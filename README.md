# scoopheap

Scoop filesystem heap paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/scoopheap/

## Install / run

```bash
git clone https://github.com/theworker02/scoopheap.git
cd scoopheap
node src/cli.js
node --test
```
